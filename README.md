# 시각장애인을 위한 핵심어 기반 대체 텍스트 생성

**Keyword-Based Alt-Text Generation for People with Visual Impairments**

2026학년도 2학기 캡스톤디자인2

## 프로젝트 소개

상품 이미지의 내용을 텍스트로 전달하는 방법을 연구한 캡스톤디자인2 프로젝트다. 시각장애인의 온라인 상품 정보 접근을 지원하는 것을 목표로 한다.

## 프로젝트 팀

**김은영 · 윤서현 · 조해인**이 데이터 수집, 실험 구현, 논문 작성 등을 수행했다.

## 관련 논문

**시각장애인을 위한 핵심어 기반 대체 텍스트 생성**

- **학회:** [대한전자공학회 2026년도 추계학술대회](https://conf.theieie.org/2026f/)
- **진행 상태:** 논문 채택 완료 · 포스터 발표 예정 (2026-11-28 발표 예정)
- **저자:** 조해인 · 김은영 · 윤서현 · 김채원 · 손서영 · 박민서
- **소속:** 서울여자대학교 데이터사이언스학과
- **교신저자:** 박민서

저자는 제출한 논문 원고의 순서에 따라 표기했다.

## MY Role

- **연구 방법 제안:** 이미지와 핵심어를 함께 활용하는 대체 텍스트 생성 방법을 제안하고 구체화했다.
- **데이터 수집:** 간편식·밀키트·샐러드와 채소 카테고리의 상품 이미지 및 메타데이터를 수집하고, 수집 코드와 데이터 정리를 담당했다.
- **생성 구현 및 실험:** 시각언어모델(VLM)을 활용한 이미지 설명문 생성과 최종 대체 텍스트 생성 코드를 작성하고 실험을 수행했다.
- **검토 및 결과 분석:** 생성 설명문을 이미지와 대조해 오류를 검토·수정하고, 생성 결과 비교와 해석에 참여했다.
- **논문 원고 작성:** 요약, 서론, 본론 중 생성 파트, 결과, 결론을 작성했다.
- **협업 환경 구축 및 진행 관리:** Notion·GitHub 공동 작업 환경을 구성하고 자료·코드·결과를 정리했다. 회의 후 담당자별 작업과 다음 회의까지의 수행 항목을 정리·공유하며 진행 상황을 관리했다.
